The Fusion Toolkit

精选关键文献、参考代码与工程笔记， 构建从纸面推导到可运行实现的技术路径。 Curated papers, reference codes and engineering notes — from paper derivations to runnable implementations.

数值工具 Numerical Tools

☢️ 辐射与反应率 Radiation & Reactivity

Xie24
轫致辐射精确拟合公式 Accurate analytical fitting of bremsstrahlung radiation
PPCF 2024 arXiv GitHub

为聚变等离子体轫致辐射提供从低温 keV 到极端相对论温区均适用的精确拟合公式，覆盖 Maxwell 及非 Maxwell 电子分布。

Xie23
聚变反应率蒙特卡罗计算 Fusion reactivity with arbitrary ion velocity distributions
CPC 2023 arXiv GitHub

简单快速的蒙特卡罗方法，高效计算任意离子速度分布（双麦氏、漂移环束、慢化分布等）下的聚变反应率。

⚖️ 平衡与输运 Equilibrium & Transport

VEQ
等离子体平衡求解器 (2D+3D) Grad-Shafranov equilibrium solver with variational parameter method
arXiv 2026 VEQ-R GitHub

基于变分参数法的 Grad-Shafranov 方程求解器，回答"最少需要几个参数才能精确表示平衡位形"这一基础问题。VEQ-R 扩展支持环向旋转效应。

VTS
输运求解器 Variational transport solver (internal)
开发中

基于变分参数法的等离子体输运求解器。

🌊 波与不稳定性 Waves & Instabilities

BORAY
轴对称射线追踪 Ray tracing for EC / LH / IC / AW waves
CPC 2022 arXiv GitHub

支持闭合与开放磁力线位形的通用射线追踪代码，覆盖电子回旋波、低杂波、离子回旋波和 Alfvén 波，已在托卡马克和偶极场中验证。

BO‑FW1D
全波吸收计算 Full-wave absorption in magnetized plasmas
PoP 2026 arXiv GitHub

鲁棒的磁化等离子体电磁波总吸收率计算方法，已在 ICRF、LHW 和 ECW 多个频段验证，集成到 BORAY 射线追踪代码中。

fluidBW
离子回旋流体模型 Fluid model with accurate kinetic Bernstein waves
PoP 2025 arXiv GitHub

首次成功构建能同时捕获动理学 Landau 阻尼和 Bernstein 模的线性流体模型，通过精确有理近似实现从 k⊥ρ→0 到 k⊥ρ→∞ 的全域覆盖。
