# Fusion Hub 聚变信息入口 — 汇报摘要

## 做了什么

搭建了聚变行业一站式信息门户 **https://veloalpha.cn/hub/**，整合全球聚变领域的核心数据资源。

## 数据规模

| 板块 | 数量 | 说明 |
|------|------|------|
| 代码库 | 100 | 含物理领域分类、开源/闭源筛选（76开源/24需申请） |
| 装置库 | 100 | 覆盖托卡马克/仿星器/FRC/惯性约束等8条路线 |
| 企业 | 99 | 国内外聚变企业，含融资规模、技术路线 |
| 融资 | 74 | 覆盖CFS/Helion/TAE等重大融资事件 |
| 新闻 | 69 | 装置建设/实验纪录/商业电站/融资动态 |
| 论文 | 99 | 含代码关联、DOI链接、摘要 |
| **合计** | **541** | |

## 技术亮点

- 数据源：飞书多维表格（6张表）→ Python 自动同步 → 网站
- 开源核查：逐一百度/谷歌验证100个代码开源状态，标注准确
- 论文关联：论文 ↔ 代码自动关联，论文详情可追溯
- 用户反馈：右下角按钮，提交后实时推送到飞书群

## 设计参考

参考 NextFusion.org 的 B2B 专业风格，温色调 + Georgia 衬线字体，响应式布局。
