OMFIT

OMFIT — One Modeling Framework for Integrated Tasks
🎮 控制/实时 开源 集成建模工作流OMFITAToM

📖 详细介绍

OMFIT 是 General Atomics 的 O. Meneghini 团队开发的磁约束聚变集成建模与实验数据分析旗舰平台。采用类似 MATLAB 的 Python 交互式环境，通过标准化接口编排数十个物理解码（EFIT、ONETWO、TGLF、TGYRO、EPED、ELITE、CQL3D 等），支持从平衡重建、输运分析到 MHD 稳定性和加热/电流驱动的全链条工作流。OMFIT 的核心优势在于一站式集成：研究人员可以在同一环境中完成实验数据导入、物理模拟、结果可视化和报告生成。已被 DIII-D、EAST、KSTAR、JET、ITER 和 CFETR 等全球主要装置广泛采用，是聚变集成建模的事实标准平台。

⚙️ 核心特性

集成建模平台 多代码编排 Python/MATLAB风格 实验-模拟闭环 全球装置标配

🔄 功能变体

实验数据分析模式（EFIT + ONETWO）；预测性输运模式（TGYRO + TGLF/GYRO）；MHD 稳定性分析模式（M3D-C1/ELITE）；GUI 交互模式；批量运行模式；Python API 开发模式。

📐 方程闭合方式

集成建模框架（非单一物理求解器），本身不求解特定方程闭合。通过统一的数据接口（OMFIT 类、OMFITtree）和工作流引擎，协调多个物理代码（EFIT、ONETWO、TGYRO、NUBEAM、M3D-C1 等）的耦合运行。数据流和物理闭合由用户配置的工作流决定——例如：EFIT 提供平衡 → TGYRO 计算输运 → 迭代至一致。框架提供图形用户界面（GUI）、Python API 和批量运行能力。数据格式基于 MDSplus 和 HDF5 的层次化树结构。

📏 归一化方案

不涉及单一归一化方案——各耦合代码使用各自的归一化，OMFIT 框架负责单位转换和数据映射。标准工作流中输入/输出以工程单位为主。
