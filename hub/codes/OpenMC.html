OpenMC

OpenMC — Open Source Monte Carlo Particle Transport Code
🔬 中子学/材料 开源 Monte Carlo中子学包层屏蔽

📖 详细介绍

OpenMC 是由 Argonne 国家实验室 Paul Romano 团队开发的新一代开源蒙特卡洛粒子输运代码，现已成为聚变中子学领域的主流开源工具。支持三维连续能量中子/光子耦合输运，具有先进的 tally 系统、CAD 几何导入（通过 DAGMC）和 MPI+OpenMP 混合并行。在聚变中，OpenMC 广泛应用于包层中子学设计（氚增殖率 TBR 计算）、屏蔽分析、核热沉积、活化计算和材料辐照损伤评估。相比传统 MCNP，OpenMC 以现代 C++/Python 架构、开源许可（MIT）和 GPU 加速路线图赢得了聚变社区尤其是私营聚变公司的青睐。

⚙️ 核心特性

蒙特卡洛中子/光子 连续能量 CAD 几何 TBR 计算 MIT 开源

🔄 功能变体

k-eigenvalue 模式（临界计算）；固定源模式（ shielding/fusion 中子学）；时间相关模式（动力学参数）；中子+光子耦合输运；CAD 几何导入（DAGMC 接口）；TBR（氚增殖比）计算；核热沉积计算；活化计算；多物理耦合（OpenMC + MOOSE/thermal-hydraulics）。

📐 方程闭合方式

求解稳态或时间相关的中子输运方程（Boltzmann 输运方程）：Ω·∇ψ(r,E,Ω) + Σt(r,E)ψ(r,E,Ω) = ∫∫ Σs(r,E'→E,Ω'→Ω)ψ(r,E',Ω') dΩ' dE' + Q(r,E,Ω)。采用蒙特卡洛方法模拟中子历史的随机游走，通过统计大量粒子获得标量通量、反应率、功率分布等。支持连续能量和multi-group截面。核数据库通过 ACE 格式截面（ENDF/B-VIII.0、JEFF-3.3 等）提供。几何通过 CSG（Constructive Solid Geometry）构建。可选包含 photon transport 和 k-eigenvalue 计算。

📏 归一化方案

采用 SI 单位和中子学惯例。长度以 cm，能量以 eV/MeV 为单位。截面以 barns（10⁻²⁴ cm²）。通量归一化通常为 per source neutron 或通过功率归一化。k-eigenvalue 无量纲。
