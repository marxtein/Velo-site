OMAS

OMAS — Ordered Multidimensional Array Structure
🔗 集成建模 开源 数据模型IMASPython工作流

📖 详细介绍

OMAS 是 ITER 集成建模与分析套件（IMAS）数据模型的 Python 实现，由 General Atomics 开发维护。提供标准化的层次数据结构，将等离子体物理数据（平衡、剖面、源项、输运等）组织为统一的 IDS（Interface Data Structure）格式，支持不同代码和机构之间的无缝数据交换。OMAS 的核心价值在于打破代码壁垒：任何遵循 IMAS 标准写入数据的代码，其输出可被任何其他 IMAS 兼容代码直接读取，无需格式转换。OMAS 还提供丰富的 Python API 用于数据查询、切片、可视化和数据库存储（支持 HDF5、MDSplus 等后端），是国际聚变集成建模生态的数据基础设施。

⚙️ 核心特性

IMAS数据标准 层次化数据结构 跨代码互操作 Python API HDF5/MDSplus后端

📐 方程闭合方式

基于 ITER IMAS 数据标准的 Python 数据访问和操作库，不直接求解物理方程。通过统一的数据模型（Interface Data Structures, IDS）管理聚变实验和模拟数据。物理闭合由用户耦合的具体代码决定。OMAS 提供标准化的数据加载/保存（JSON/HDF5/NetCDF/IMAS）、数据映射（将不同代码的输入/输出映射到统一 IDS 格式）和可视化工具。核心价值在于提供代码间数据互操作的标准接口，是集成建模基础设施。

闭合方程组
$$\text{OMAS 提供数据映射层，不涉物理闭合。}\quad \mathcal{M}: \text{Code}_A \leftrightarrow \text{IDS} \leftrightarrow \text{Code}_B$$

📏 归一化方案

以工程单位为主。温度以 eV/keV，密度以 m⁻³，长度以 m，磁场以 T，电流以 A/MA。各代码的归一化通过 OMAS 映射层自动转换。

归一化关系
$$\bar{T}[\text{eV}],\; \bar{n}[\text{m}^{-3}],\; \bar{B}[\text{T}] \quad \text{(IDS 标准单位)}$$

🔄 功能变体

Python 独立库模式；OMFIT 集成模式；IMAS 数据服务器模式；本地文件模式（JSON/HDF5）；批量数据处理模式。

IMAS 兼容
