OMAS

OMAS — Ordered Multidimensional Array Structure
🔗 集成建模 开源 数据模型IMASPython工作流

📖 详细介绍

OMAS 是 ITER 集成建模与分析套件（IMAS）数据模型的 Python 实现，由 General Atomics 开发维护。提供标准化的层次数据结构，将等离子体物理数据（平衡、剖面、源项、输运等）组织为统一的 IDS（Interface Data Structure）格式，支持不同代码和机构之间的无缝数据交换。OMAS 的核心价值在于打破代码壁垒：任何遵循 IMAS 标准写入数据的代码，其输出可被任何其他 IMAS 兼容代码直接读取，无需格式转换。OMAS 还提供丰富的 Python API 用于数据查询、切片、可视化和数据库存储（支持 HDF5、MDSplus 等后端），是国际聚变集成建模生态的数据基础设施。
