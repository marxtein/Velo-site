TASK

TASK — Total Analysis Suite for Tokamak Plasmas
🔬 其他 需申请 集成建模输运

📖 详细介绍

TASK 是由日本京都大学福山淳（Atsushi Fukuyama）教授团队开发的托卡马克等离子体集成模拟套件，也是日本燃烧等离子体模拟计划（BPSI）的核心代码框架。TASK 采用模块化架构，包含多个独立模块——TASK/TR（输运）、TASK/WM（全波加热分析）、TASK/EQ（平衡）、TASK/FP（Fokker-Planck 动理学）等——通过标准化接口和公共数据格式实现模块间数据传递和协同仿真。代码覆盖从芯部到边界的多物理过程，支持不同保真度级别的输运模型切换，是亚洲聚变集成建模生态的重要支柱。TASK 与欧洲的 ITM/IMAS 框架保持接口兼容，用于 JT-60SA 和 ITER 的预测性模拟。

⚙️ 核心特性

集成模拟 模块化架构 全波加热 输运模型 JT-60SA

🔄 功能变体

TASK/TR 输运模式；TASK/WM 全波加热模式；TASK/EQ 平衡重建模式；TASK/FP Fokker-Planck 模式；JT-60SA 集成模式；ITER 集成模式。

📐 方程闭合方式

京都大学开发的模块化托卡马克集成模拟套件，日本燃烧等离子体模拟计划（BPSI）的核心代码框架。模块包括：TASK/TR（1D 输运）、TASK/WM（全波加热，ICRF/ECRH/LH）、TASK/EQ（2D Grad-Shafranov 平衡）、TASK/FP（Fokker-Planck 动理学）。各模块通过标准化接口和公共数据格式交换数据，支持不同保真度级别的输运模型切换。与欧洲 ITM/IMAS 框架保持接口兼容。

📏 归一化方案

采用工程单位（SI）。各模块内部可转换为适合的归一化方案。
