UEDGE

UEDGE — 2D Edge Plasma Fluid Code
🔥 边界/偏滤器 开源 有限体积边界偏滤器SOL

📖 详细介绍

UEDGE 是 LLNL（劳伦斯利弗莫尔国家实验室）开发的二维等离子体边界流体模拟代码，是刮削层/偏滤器物理的经典工具。采用 2D 多流体方程（电子、离子独立温度），耦合简化中性粒子模型或 DEGAS 中性蒙特卡洛代码。主要应用于偏滤器等离子体参数分布预测、杂质辐射和脱靶分析，特别在 DIII-D 装置上得到广泛验证。UEDGE 是 SOLPS-ITER 之前的边界流体模拟先行者，至今仍在 NSTX-U、DIII-D 等装置上活跃使用。

⚙️ 核心特性

2D流体 多流体模型 偏滤器模拟 中性粒子耦合 DIII-D验证

📐 方程闭合方式

求解 2D 多流体（电子 + 多种离子）等离子体输运方程在托卡马克刮削层/偏滤器区域。控制方程包括：粒子连续性、平行动量、电子能量、离子能量。包含经典输运（平行 Braginskii 系数）和反常输运（用户指定的径向扩散/热导率）。中性粒子通过简化流体模型或耦合 DEGAS Monte Carlo 代码处理。电磁场通过电流连续性方程 + 鞘层边界条件闭合。偏滤器靶板使用 Bohm 鞘层条件。是 SOLPS 之前的经典边界流体代码。

闭合方程组
$$ \begin{aligned} \frac{\partial n}{\partial t} + \nabla\cdot(n\mathbf{V}) &= S_n \\[4pt] \frac{\partial}{\partial t}(mnV_\parallel) + \nabla\cdot(mnV_\parallel\mathbf{V}) &= -\nabla_\parallel p + S_p \\[4pt] \frac{3}{2}\frac{\partial(nT)}{\partial t} + \nabla\cdot(\mathbf{q} + \tfrac{5}{2}nT\mathbf{V}) &= Q \\[4pt] V_\parallel^{\text{target}} &\geq c_s = \sqrt{\frac{T_e + T_i}{m_i}} \end{aligned} $$

📏 归一化方案

采用工程单位。密度以 m⁻³，温度以 eV，通量以 m⁻²s⁻¹，功率以 W/m² 为单位。

归一化关系
$$\bar{n}[\text{m}^{-3}],\; \bar{T}[\text{eV}],\; \bar{\Gamma}[\text{m}^{-2}\text{s}^{-1}]$$

🔄 功能变体

纯等离子体模式（无中性粒子）；DEGAS MC 中性粒子耦合；简化中性粒子流体模式；D/T/He/杂质多离子；DIII-D 专用配置；NSTX-U 配置。

DEGAS中性粒子

$$S_n, S_p, Q \leftarrow \text{DEGAS Monte Carlo}$$
