VPIC

VPIC — Vector Particle-In-Cell Code
🧲 MHD平衡/稳定 开源 PIC磁重联激光等离子体Exascale

📖 详细介绍

VPIC 是 LANL（洛斯阿拉莫斯国家实验室）开发的高性能相对论全电磁 PIC 代码，专为大规模并行架构优化。采用矢量数据结构和混合模式并行（MPI+线程），在 Exascale 超级计算机上实现极高效率的粒子推送和场求解。主要应用于磁重联、湍流、激光等离子体相互作用和高能量密度物理。VPIC 以极简实现实现顶级性能，2024 年在 Frontier 等 Exascale 系统上展示了数十亿粒子规模的激光聚变模拟。

⚙️ 核心特性

全电磁PIC 矢量数据结构 Exascale 磁重联 激光等离子体

📐 方程闭合方式

求解相对论全电磁 PIC 方程组。采用矢量数据结构优化，充分利用 SIMD 向量化。Maxwell 方程组采用 FDTD Yee 网格和电荷守恒电流沉积。粒子推进使用相对论 Boris 算法。解决完整 Maxwell 方程（非约化），适用于无鞘层假设的全动理学等离子体。并行采用混合模式 MPI+线程，面向 Exascale 架构优化的数据布局（粒子按空间排序以最大化缓存效率）。

📏 归一化方案

采用 SI 单位和归一化单位双支持。归一化通常基于等离子体频率 ωpe（时间）、skin depth c/ωpe（长度）和参考密度 n₀。对于激光-等离子体问题，也支持基于激光参数的归一化。磁场归一化到 B₀ = mωpec/e。

🔄 功能变体

1D/2D/3D 几何；静电/全电磁；Exascale 优化模式（GPU 加速）；磁重联专用配置；激光-等离子体相互作用；高能量密度物理；粒子排序优化（提升缓存命中率）；矢量数据布局（AVX-512 优化）。
