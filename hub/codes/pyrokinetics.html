pyrokinetics

pyrokinetics — Python Interface for Gyrokinetic Microstability Analysis
🔬 其他 开源 工作流回旋动理学数据转换Python

📖 详细介绍

pyrokinetics 是 UKAEA 开发的 Python 回旋动理学工作流工具包，旨在解决多回旋动理学代码（GS2、CGYRO、GENE、stella）之间输入输出格式不统一的核心痛点。提供统一的 Python 接口读取各代码的输入文件（平衡几何、动理学剖面、等离子体参数）和输出文件（增长率、本征模结构、通量），支持代码间无缝切换和基准对比。pyrokinetics 还集成了自动化的线性稳定性分析流水线（扫描 k_y 谱、参数扫描），使跨代码验证和非专家用户使用回旋动理学代码的门槛大幅降低。已成为 EUROfusion 湍流输运验证与确认工作包的核心工具。

⚙️ 核心特性

多代码格式转换 统一 Python 接口 跨代码基准对比 线性稳定性流水线 GS2/CGYRO/GENE/stella
