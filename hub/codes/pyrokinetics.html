pyrokinetics

pyrokinetics — Python Interface for Gyrokinetic Microstability Analysis
🔬 其他 开源 工作流回旋动理学数据转换Python

📖 详细介绍

pyrokinetics 是 UKAEA 开发的 Python 回旋动理学工作流工具包，旨在解决多回旋动理学代码（GS2、CGYRO、GENE、stella）之间输入输出格式不统一的核心痛点。提供统一的 Python 接口读取各代码的输入文件（平衡几何、动理学剖面、等离子体参数）和输出文件（增长率、本征模结构、通量），支持代码间无缝切换和基准对比。pyrokinetics 还集成了自动化的线性稳定性分析流水线（扫描 k_y 谱、参数扫描），使跨代码验证和非专家用户使用回旋动理学代码的门槛大幅降低。已成为 EUROfusion 湍流输运验证与确认工作包的核心工具。

⚙️ 核心特性

多代码格式转换 统一 Python 接口 跨代码基准对比 线性稳定性流水线 GS2/CGYRO/GENE/stella

📐 方程闭合方式

Python 库，用于在不同回旋动理学代码（GENE、GS2、CGYRO、GX、stella 等）之间转换输入/输出格式。不直接求解物理方程——通过标准化的数据格式（基于 xarray 的 Pyro 对象）在代码间映射平衡几何（Miller 磁面参数）、等离子体剖面（密度、温度、旋转）、电磁涨落设置和归一化参数。物理闭合由调用的回旋动理学代码决定。大大简化了多代码基准对比（benchmarking）和不确定性量化工作流。

闭合方程组
$$ \mathcal{M}: \text{input.gacode} \xrightarrow[\text{pyro}]{} \{\text{GENE}, \text{CGYRO}, \text{GS2}, \text{GX}, \text{stella}, \text{TGLF}\} $$

📏 归一化方案

输入剖面以工程单位（keV, 10¹⁹ m⁻³, m）提供，内部自动转换为各目标代码所需的归一化方案（GENE 的 gyro-Bohm、CGYRO 的 ρs 归一化等）。归一化参数在 Pyro 对象中集中管理。

归一化关系
$$\text{自动转换: 工程单位} \leftrightarrow \text{各代码归一化}$$

🔄 功能变体

GENE 输入/输出转换；GS2 转换；CGYRO 转换；GX 转换；stella 转换；TGLF 转换；多代码 benchmark 模式；profile 参数扫描模式。

多代码benchmark

$$\Delta \chi = \frac{|\chi_A - \chi_B|}{\chi_A + \chi_B} < \varepsilon$$
