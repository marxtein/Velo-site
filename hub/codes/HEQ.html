HEQ

HEQ — Python Free-Boundary Equilibrium Reconstruction
🧲 MHD平衡/稳定 开源 平衡反演Python自由边界

📖 详细介绍

HEQ 是中科院等离子体物理研究所胡友俊团队开发的纯 Python 自由边界等离子体平衡重建代码。采用有限差分方法在 (R,Z) 平面求解自由边界 Grad-Shafranov 方程，支持 PF 线圈电流约束和磁诊断信号拟合，功能类似于 EFIT 但以代码简洁性和可读性为设计优先。HEQ 全部用 Python 编写（核心求解器使用 NumPy/SciPy），代码量仅数千行，非常适合教学、快速原型开发和算法验证。已被国内多家聚变研究机构用于平衡重建方法的教学和初步分析，其开放架构允许用户方便地替换求解器、添加新诊断约束或耦合其他物理解码。

⚙️ 核心特性

纯Python实现 自由边界平衡 磁诊断拟合 教学/原型开发 NumPy/SciPy
