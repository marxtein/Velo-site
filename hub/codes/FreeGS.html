FreeGS

FreeGS — Free-Boundary Grad-Shafranov Equilibrium Solver
🧲 MHD平衡/稳定 开源 Grad-Shafranov自由边界平衡Python

📖 详细介绍

FreeGS 是英国 York 大学 Ben Dudson 团队开发的轻量级 Python 自由边界 Grad-Shafranov 平衡求解器。采用有限差分法在 (R,Z) 平面求解 Grad-Shafranov 方程，支持自由边界和固定边界两种模式，可处理 PF 线圈电流约束和 X 点搜索。FreeGS 以代码简洁、易于教学和快速原型著称，是 BOUT++ 生态的平衡求解组件，常嵌入 Jupyter Notebook 中用作教学演示和控制算法原型开发。核心代码仅约 2000 行，是理解和修改最低门槛的等离子体平衡求解器之一。

⚙️ 核心特性

自由边界 GS 平衡 Python 纯实现 X 点搜索 教学/原型开发 BOUT++ 生态组件
