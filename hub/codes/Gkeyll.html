Gkeyll

Gkeyll — Discontinuous Galerkin Gyrokinetic Code
🌊 湍流输运 开源 间断伽辽金动理学Vlasov-MaxwellSOL

📖 详细介绍

Gkeyll 是由 Ammar Hakim 团队开发的高阶间断伽辽金（DG）动理学代码，同时支持 Vlasov-Maxwell 和回旋动理学模型。采用能量守恒的半离散 DG 格式，在速度空间使用 discontinuous Galerkin 方法，能够实现无噪声（noise-free）的动理学模拟。主要用于托卡马克边界刮削层（SOL）湍流、鞘层物理、等离子体-壁相互作用等边界等离子体问题，也可用于空间等离子体基础研究。2023-2024 年扩展了电磁回旋动理学能力，支持全 f 分布函数演化，是边界湍流研究的重要前沿代码。

⚙️ 核心特性

间断伽辽金 动理学 无噪声模拟 SOL湍流 鞘层物理 Vlasov-Maxwell

🔄 功能变体

全 Vlasov-Maxwell 模式（空间等离子体）；回旋动理学模式（磁约束聚变）；1D/2D/3D 几何；静电/电磁；线性/非线性；无碰撞/含碰撞（Dougherty-Fokker-Planck 碰撞算符）；SOL 边界湍流专用配置；鞘层物理模块。

📐 方程闭合方式

采用高阶间断伽辽金（Discontinuous Galerkin, DG）方法求解 Vlasov-Maxwell 或回旋动理学方程系统。方程直接在完整相空间中离散（含速度空间维度），实现无噪声（noise-free）的动理学模拟。场方程通过 Maxwell 方程组（全 Vlasov-Maxwell 模式）或回旋动理学 Poisson-Ampere 方程闭合。采用能量守恒的半离散 DG 格式，每个单元内使用高阶多项式基函数（通常 2-4 阶）。支持全 f 分布函数演化（非 δf 近似），特别适合边界物理（强梯度、非 Maxwell 分布）。

📏 归一化方案

采用标准等离子体归一化方案。长度以离子惯性长度 di = c/ωpi 或 Debye 长度 λD 归一化，时间以等离子体频率 ωpe⁻¹ 或离子回旋频率 Ωci⁻¹ 归一化。速度以热速度或 Alfvén 速度归一化。具体归一化取决于所求解的物理问题。
