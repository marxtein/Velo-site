GVEC

GVEC — Galerkin Variational Equilibrium Code
🧲 MHD平衡/稳定 开源 平衡谱方法恒星器

📖 详细介绍

GVEC 是 IPP Greifswald 开发的新一代三维理想 MHD 平衡求解器，采用高精度 B 样条有限元和 Galerkin 变分方法，适用于任意三维磁约束装置（仿星器、托卡马克）。与 VMEC 不同，GVEC 不假设嵌套磁面存在，可在部分破坏磁面的区域自然求解。核心采用现代 Fortran 编写，通过 MPI+OpenMP 并行，提供 Python 包接口（pip install gvec），2025 年以论文形式发表在 Journal of Open Source Software。GVEC 被定位为 VMEC 的下一代替代方案——在计算精度、灵活性和易用性上全面升级，已被 SIMSOPT 等仿星器优化框架集成，是仿星器社区向现代化开源生态转型的关键代码。

⚙️ 核心特性

B样条Galerkin有限元 三维MHD平衡 通用磁约束几何 Python+Fortran VMEC下一代替代
