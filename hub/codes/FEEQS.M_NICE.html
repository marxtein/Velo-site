FEEQS.M/NICE

FEEQS.M/NICE — Finite Element Equilibrium Solver for Tokamaks
🧲 MHD平衡/稳定 需申请 平衡有限元

📖 详细介绍

FEEQS.M 和 NICE 是 PPPL（普林斯顿等离子体物理实验室）开发的托卡马克有限元平衡求解器系列。FEEQS.M 采用自由边界有限元方法求解 Grad-Shafranov 方程，支持任意等离子体截面形状和外部导体配置，可用于实验平衡重建和理论位形分析。NICE（New Inverse Code for Equilibrium）是其变体，专注于反问题——即给定所需的等离子体边界和内部剖面，反演计算所需的线圈电流配置。两者共同构成 PPPL 平衡分析工具链的关键环节，支撑 NSTX-U、LTX-beta 等球形托卡马克和锂壁托卡马克的平衡分析。代码以 Fortran 编写，高效稳定，在 PPPL 实验中经过数十年验证。

有限元平衡 自由边界 NSTX-U 反问题 PPPL

🔬 物理模型与功能变体

基础物理模型

FEEQS.M 使用自由边界有限元方法求解 Grad-Shafranov 方程，支持任意等离子体截面形状和外部导体配置。NICE（New Inverse Code for Equilibrium）是其变体，求解逆问题：给定所需的等离子体边界和内部剖面，反演计算实现该平衡所需的线圈电流配置。是 PPPL 平衡分析工具链的关键环节，支持 NSTX-U、LTX-β 等球形托卡马克和锂壁托卡马克的平衡分析。

基础闭合方程组
$$ \begin{aligned} \text{FEEQS.M:}&\quad \Delta^*\psi = -\mu_0 R^2 p' - FF' + \mu_0 R J_{\text{coils}} \\[4pt] \text{NICE:}&\quad \min_{\mathbf{I}} \|\psi - \psi_{\text{target}}\|^2 \;\text{s.t.}\; \Delta^*\psi = f(\psi, \mathbf{I}) \end{aligned} $$

FEEQS.M 正问题（给定线圈电流→求解平衡）；NICE 逆问题（给定等离子体→反演线圈电流）；NSTX-U 配置；LTX-β 配置。

NSTX-U球形环

$$\varepsilon = a/R_0 \geq 0.5 \;\text{(球形托卡马克)}$$

📏 归一化方案

采用 SI 工程单位。磁场以 T，电流以 A，ψ 以 Wb 为单位。
