Power Balance Models

PBM — Power Balance Models for Fusion Reactor Design
🔬 其他 开源 系统代码功率平衡反应堆工程

📖 详细介绍

PBM（功率平衡模型）是 UKAEA 开发的开源框架，用于评估不同托卡马克聚变反应堆设计的净功率产出。基于 Modelica 建模语言构建功率消耗（磁体、低温、加热与电流驱动、泵送等）和功率产生（聚变输出、热能转换）系统的物理模型，通过 Python API 和 CLI 接口提供快速配置和批量仿真能力。PBM 专为反应堆概念设计早期阶段设计——可在数秒至数分钟内回答该设计能否产生净电力这一核心问题。已成功应用于 STEP 原型电站的参数扫描和设计点优化中，同时支持托卡马克和仿星器两种磁约束方案。PBM 的模块化架构允许用户替换任意子系统模型，适配从概念探索到详细工程的多种保真度需求。

基础物理模型

UKAEA 开发的 Modelica 建模框架，通过功率平衡模型评估不同托卡马克聚变反应堆设计的净功率输出。子系统模型（磁体冷却、低温系统、加热与电流驱动、泵送、聚变功率产生、热能转换）通过 Modelica 方程耦合。使用 Python API 和 CLI 接口提供快速配置和批量仿真。设计用于反应堆概念设计早期阶段回答"该设计能否产生净电力"这一核心问题。已成功应用于 STEP 原型电站的参数扫描和设计点优化。
