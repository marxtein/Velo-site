OSIRIS

OSIRIS — Relativistic Electromagnetic PIC Code
🧲 MHD平衡/稳定 开源 PIC激光等离子体LWFA高能量密度物理

📖 详细介绍

OSIRIS 是 UCLA 等离子体模拟组和葡萄牙 IST 联合开发的相对论全电磁 PIC 代码，是激光等离子体加速领域的标杆性模拟工具。支持 1D/2D/3D 全电磁模型、电流沉积和电荷守恒方案、动态负载平衡和 MPI+OpenMP 并行。主要应用于激光尾波电子加速（LWFA）、质子加速（TNSA/RPA）、正电子产生、惯性约束聚变中的激光-等离子体相互作用和强场 QED 效应。OSIRIS 的开创性模拟直接推动了激光等离子体加速领域的多项实验突破。

⚙️ 核心特性

全电磁PIC 激光尾波加速 电荷守恒 QED效应 并行负载平衡

🔄 功能变体

1D/2D/3D 几何；标准激光尾波加速模式（LWFA）；质子加速模式（TNSA/RPA）；正电子产生；QED 模块（强场量子电动力学）；移动窗口；动态负载平衡；MPI+OpenMP 并行；静电/全电磁/准静态模式。

📐 方程闭合方式

求解相对论全电磁 PIC 方程组。Maxwell 方程组采用 FDTD 方法在交错 Yee 网格上离散，使用电荷守恒电流沉积方案（Villasenor-Buneman 或 Esirkepov）保证 ∇·E = ρ/ε₀。粒子推进采用相对论 Boris 推子。电磁模型为全 Maxwell（保留位移电流），支持激光-等离子体和高能量密度物理。可选包含强场 QED 效应（非线性 Compton 散射、Breit-Wheeler 对产生）通过 Monte Carlo 模块耦合。采用移动窗口（moving window）技术尾随激光脉冲。

📏 归一化方案

采用激光-等离子体常用归一化。长度以激光波长 λ₀ 的 1/(2π) 归一化，时间以激光频率 ω₀⁻¹ 归一化，密度以临界密度 nc = ε₀mω₀²/e² 归一化。电磁场以 mω₀c/e 归一化（使无量纲激光强度 a₀ = eE/mω₀c）。粒子能量以 mec² 归一化。
