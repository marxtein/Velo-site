SPEC

SPEC — Stepped Pressure Equilibrium Code
🧲 MHD平衡/稳定 开源 谱元法MRxMHD磁岛仿星器

📖 详细介绍

SPEC 是普林斯顿大学 Stuart Hudson 和 PPPL 团队开发的三维 MHD 平衡求解器，创新性地采用多区域变分原理（MRxMHD），将等离子体划分为多个嵌套的压力台阶区域。与 VMEC 不同，SPEC 不假设全局磁面存在，可自然处理磁岛、随机磁场区域和部分破坏的磁面结构。这使得 SPEC 在分析仿星器磁岛物理、三维 MHD 平衡分岔和会切/开放场线区域（如 W7-X 岛偏滤器）方面具有独特优势。SPEC 正在成为仿星器和三维托卡马克平衡物理研究的重要补充工具。

⚙️ 核心特性

多区域MHD 磁岛处理 变分原理 仿星器专用 压力台阶

🔄 功能变体

少数区域模式（2-3 区，快速扫描）；多区域模式（10+ 区，精细结构）；固定边界；自由边界（真空区）；轴对称模式（托卡马克）；三维仿星器模式；磁岛分岔分析模式；会切/岛偏滤器分析模式。

📐 方程闭合方式

基于多区域变分 MHD（MRxMHD）原理。将等离子体划分为多个嵌套的体积区域，每个区域内压力为常数（压力台阶），区域间通过理想 MHD 界面条件连接。在每个区域内求解 Beltrami 方程 ∇ × B = μB（力自由场），区域边界处通过压力跳跃 Δp 平衡。不假设全局嵌套磁面存在，可自然处理磁岛链、随机场线区域和部分破坏的磁面。界面几何通过最小化总 MHD 能量（含界面能）的变分原理确定。区域数量和压力分布为输入。

📏 归一化方案

采用无量纲单位。长度以参考大半径归一化，磁场以参考环向场归一化。压力以 Bref²/(2μ₀) 归一化。各区域的 Beltrami 参数 μ 为输入。总环向磁通作为径向标签。
