NEMO

NEMO — Neutral Beam Injection Monte Carlo Birth Code for Stellarators
⭐ 仿星器优化 开源 优化平衡恒星器

📖 详细介绍

NEMO 是 IPP Greifswald 开发的仿星器中性束注入（NBI）快离子诞生蒙特卡洛代码。在三维仿星器复杂磁场几何中计算 NBI 中性粒子电离产生的快离子初始分布函数——包括电离位置、初始能量、投掷角分布和轨道类型分类。NEMO 的核心输出是快离子源项，直接输入 ASCOT5 等轨道追踪代码进行约束和损失分析。在 W7-X 的 NBI 系统设计和优化中发挥了关键作用，用于评估不同 NBI 注入角度和能量对快离子约束性能的影响。NEMO 精确处理仿星器的三维磁场波纹结构对中性束衰减和电离的影响，是仿星器高能粒子物理研究的基础工具。

⚙️ 核心特性

NBI快离子诞生 仿星器3D几何 蒙特卡洛方法 快离子源项计算 W7-X设计优化

📐 方程闭合方式

IPP Greifswald 开发的仿星器几何中 NBI（中性束注入）蒙特卡洛模拟代码。通过追踪中性粒子在三维仿星器等离子体中的电离过程（电子碰撞电离 + 离子碰撞电离 + 电荷交换），计算快离子源分布（birth profile）。NBI 束的中性粒子沿直线传播，直到发生电离碰撞。电离截面来自标准原子数据库。等离子体背景由 VMEC/SPEC（MHD 平衡）和剖面模型提供。是仿星器 NBI 加热和电流驱动分析的标准工具。

📏 归一化方案

采用 SI 工程单位。束能量以 keV，功率以 MW，位置以 m，密度以 m⁻³ 为单位。

🔄 功能变体

仿星器几何模式；托卡马克几何模式（早期版本）；单束线/多束线；稳态 source 模式；时间相关模式；功率沉积剖面；快离子 slowing-down 分布（耦合 ASCOT）。
