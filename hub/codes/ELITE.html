ELITE

ELITE — Edge Localized Instability Tokamak Experiment Code
🧲 MHD平衡/稳定 需申请 稳定性剥离气球模

📖 详细介绍

ELITE 是 General Atomics 开发的专用托卡马克边界高环向模数（high-n）理想 MHD 不稳定性代码，是 peeling-ballooning 模分析的标准工具。在气球模理论的扩展框架下，采用渐近分析方法高效求解边界（pedestal）区域的高 n 剥离-气球模稳定性边界。ELITE 的核心功能是计算 pedestal 区域的不稳定性阈值，直接输出 pedestal 压强梯度（alpha）和 pedestal 电流（剥离）的稳定性空间图。ELITE 是 EPED pedestal 预测模型的核心组件（提供 peeling-ballooning 稳定性约束），广泛用于预测 H 模式 pedestal 结构、ELM 触发条件和 ELM 缓解方案的评估。

⚙️ 核心特性

high-n气球模 剥离-气球模稳定性 pedestal物理 EPED核心组件 ELM预测

🔄 功能变体

有限 n 模式（n=5~50）；无限 n ballooning；peeling mode 分析；pedestal 稳定性边界；ELM 触发预测；EPED 模型集成。

📐 方程闭合方式

GA 开发的 peeling-ballooning（P-B）MHD 稳定性代码，专门分析托卡马克 pedestal 区域的耦合 peeling（电流驱动）和 ballooning（压强梯度驱动）不稳定性。求解理想 MHD 运动方程的变分形式，在 pedestal 区域使用高分辨率网格。计算无限 n（ballooning）和有限 n（peeling-ballooning）模式的稳定性边界，用于预测 ELM 触发条件和 pedestal 高度（通过 EPED 模型的 P-B 约束分支）。

📏 归一化方案

采用归一化单位。长度以 ψN（归一化 poloidal flux），磁场和压力以参考值归一化。增长率和频率以 Alfvén 时间归一化。
