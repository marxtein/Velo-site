REMA

REMA — Resistive MHD Stability Code
🧲 MHD平衡/稳定 需申请 稳定性有限元

📖 详细介绍

REMA 是法国原子能与替代能源委员会（CEA-IRFM）开发的电阻 MHD 稳定性分析代码，采用有限元方法在环形几何中求解全电阻 MHD 方程组的本征值问题。代码专门用于分析托卡马克中电阻性不稳定性——包括撕裂模（tearing mode）、新经典撕裂模（NTM）和电阻壁模（RWM）的线性增长率和模结构，是理解等离子体破裂前兆、评估 beta 极限和设计稳定性控制方案的重要数值工具。REMA 与 CEA 的 CRONOS、METIS 等集成建模代码对接，为 JET 和 ITER 稳态 scenario 开发提供稳定性边界。代码以 Fortran 编写，经过 WEST（钨环境稳态托卡马克）实验的验证。

⚙️ 核心特性

电阻MHD 本征值分析 撕裂模/NTM CEA WEST验证

📐 方程闭合方式

CEA-IRFM 开发的电阻 MHD 稳定性分析代码。采用有限元方法在环形几何中求解全电阻 MHD 方程组的线性本征值问题。计算撕裂模（tearing mode）、新经典撕裂模（NTM）和电阻壁模（RWM）等电阻性不稳定性的线性增长率和模结构。是 WEST 装置和 ITER 稳定性分析的工具之一。与 CRONOS/METIS 等集成建模代码对接，为稳态 scenario 开发提供稳定性边界。

闭合方程组
$$ \begin{aligned} \rho\frac{\partial\mathbf{V}}{\partial t} &= \mathbf{J}\times\mathbf{B} - \nabla p + \nu\nabla^2\mathbf{V} \\[4pt] \frac{\partial\mathbf{B}}{\partial t} &= \nabla\times(\mathbf{V}\times\mathbf{B}) - \nabla\times(\eta\mathbf{J}) \\[4pt] \Delta' &= \frac{\psi'(r_s^+) - \psi'(r_s^-)}{\psi(r_s)} \;\text{(tearing mode stability index)} \end{aligned} $$

📏 归一化方案

采用 Alfvén 归一化。增长率以 τA⁻¹，电阻以 Lundquist 数表征。磁 Reynolds 数以 S = τR/τA 表示。

归一化关系
$$\bar{t} = t/\tau_A,\; S = \tau_R/\tau_A,\; \Delta' \;\text{(无量纲)}$$

🔄 功能变体

tearing mode 分析；NTM 分析；RWM 分析；CRONOS/METIS 集成；WEST 专用配置；ITER 稳定性评估。

NTM分析

$$\Delta' + \Delta'_{\text{bootstrap}} = 0 \;\Rightarrow\; \text{marginal stability}$$
