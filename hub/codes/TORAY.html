TORAY

TORAY — Electron Cyclotron Ray Tracing Code
🌊 湍流输运 开源 射线追踪ECRH

📖 详细介绍

TORAY 是 General Atomics 开发的电子回旋波（EC）专用射线追踪和电流驱动计算代码。采用冷等离子体色散关系和四阶 Runge-Kutta 方法追踪 EC 波在托卡马克等离子体中的传播轨迹。相比 GENRAY 的通用性，TORAY 专精 EC 波段，提供了更精确的相对论吸收系数计算（Mazzucato 公式）和电流驱动效率评估（包括 trapped particle 效应修正）。TORAY 通常作为 CQL3D 的 EC 前端，提供波功率沉积剖面作为 Fokker-Planck 计算的输入。是 DIII-D EC 加热系统设计和实验分析的标准工具，也被 ITER EC 系统设计中广泛参考。

⚙️ 核心特性

EC专用射线追踪 Runge-Kutta方法 相对论吸收 ECCD电流驱动 CQL3D前端

📐 方程闭合方式

与 GENRAY 类似，求解 EC 波射线追踪方程，但专门针对电子回旋波（EC）的加热和电流驱动。使用冷等离子体色散关系或 weakly relativistic 修正。求解 dr/dt = vg 和 dk/dt（含 relativistic 和热修正项）。计算沿射线的功率衰减（通过吸收系数）和驱动的电流密度（通过 adjoint 方法或 Fokker-Planck 响应函数）。是 GA 和 PPPL 装置上 EC 系统设计的标准工具。

闭合方程组
$$ \begin{aligned} \frac{d\mathbf{r}}{dt} &= -\frac{\partial D/\partial \mathbf{k}}{\partial D/\partial \omega},\quad \frac{d\mathbf{k}}{dt} = \frac{\partial D/\partial \mathbf{r}}{\partial D/\partial \omega} \\[4pt] D(\omega,\mathbf{k},\mathbf{r}) &= \det\left[\frac{c^2}{\omega^2}(\mathbf{k}\mathbf{k} - k^2\mathbf{I}) + \boldsymbol{\varepsilon}(\omega,\mathbf{k},\mathbf{r})\right] = 0 \\[4pt] \frac{dP}{dt} &= -2\gamma(\mathbf{r},\mathbf{k}) P,\quad \gamma = \text{Im}(\omega) \end{aligned} $$

📏 归一化方案

与 GENRAY 类似。频率以 GHz，功率以 MW，位置以 m，磁场以 T 为单位。内部计算使用归一化等离子体单位。

归一化关系
$$\bar{\omega} = \frac{\omega}{\Omega_{ce}},\; \bar{k} = \frac{kc}{\omega_{pe}},\; \bar{\mathbf{r}} = \frac{\mathbf{r}}{R_0}$$

🔄 功能变体

EC 射线追踪（标配）；O-mode/X-mode 选择；线性吸收；准线性吸收（有限功率展宽）；电流驱动效率计算（Ehst-Karney 或 adjoint 方法）。

ECCD效率

$$\eta_{\text{CD}} = \frac{\bar{R} n_e I_{\text{CD}}}{P_{\text{EC}}} \times 10^{20}\;\text{A/W/m}^2$$
