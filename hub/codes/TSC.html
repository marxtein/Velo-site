TSC

TSC — Tokamak Simulation Code
🔬 其他 开源 平衡演化控制

📖 详细介绍

TSC 是普林斯顿大学/PPPL 开发的二维自由边界时变托卡马克等离子体模拟代码。在 (R,Z) 平面求解耦合的 Grad-Shafranov 平衡、表面平均输运方程和 PF 线圈电路方程，自洽模拟等离子体位形和电流剖面的时间演化。TSC 特别擅长处理等离子体大半径移动、拉长比变化和 beta 演化等宏观动力学过程，是托卡马克放电方案设计（波形开发）和等离子体控制算法预验证的经典工具。TSC 被 SPARC、ITER 和 KSTAR 等多个装置用于放电方案预研和垂直不稳定性分析。

⚙️ 核心特性

2D 自由边界 时变放电模拟 电流剖面演化 放电方案设计 垂直不稳定性

🔄 功能变体

全放电模拟（breakdown to termination）；自由边界演化；铁芯变压器模型；NBI/ICRF/ECRH 加热耦合；不同输运模型选项；等离子体控制仿真。

📐 方程闭合方式

求解轴对称（2D）时变自由边界托卡马克等离子体演化方程。耦合求解 Grad-Shafranov 平衡、等离子体输运（1D 径向输运方程——电子和离子温度、粒子密度、电流扩散）和外部电路方程（主动线圈 + 被动导体）。输运闭合通过经验或理论输运模型提供。加热和电流驱动通过参数化模块（NBI/ICRF/ECRH/LH）耦合。支持包含铁磁材料（iron core）的变压器模型。是经典的全放电模拟代码，用于托卡马克 scenario 开发和装置设计。

📏 归一化方案

采用 SI 工程单位。长度以 m，时间以 s，温度以 eV，密度以 m⁻³，电流以 A，磁场以 T 为单位。
