2026.07.14

多位形聚变装置零维系统设计程序 VSC 上线

VSC, a multi-configuration zero-dimensional system design code for fusion devices, goes online.

瞬原科技正式上线 VeloAlpha System Code V1（简称 VSC）。VSC 是一套面向磁约束聚变装置早期设计的多位形零维系统程序，当前支持托卡马克、磁镜、场反位形（FRC）、偶极场和仿星器五类磁约束位形。用户可以通过浏览器选择装置概念、设置参数，进行单点计算、几何查看和二维 POPCON 扫描，从而分析某一候选方案在给定物理假设下的聚变功率、外部加热需求、聚变能量增益、辐射损失、输运损失和运行限制。查看详情 →
