Open Source / 开源

开源

代码、数据、路线图、社区机制 — 将按成熟度分阶段发布， 方向不变：让每一行核心代码都被同行检验。 Code, data, roadmap and governance are released in phases as each layer becomes reproducible.

veloalpha@fusion : ~ / opensource phased

$ ls open-source/

repo CODE phase-01

datasets DATA phase-02

docs DOCS phase-02

roadmap ROADMAP phase-03

community COMMUNITY phase-03

$ _

01 CODE

代码公开

Core engines, key modules, and build scripts — opened in phases, open to scrutiny.

核心引擎、关键模块、构建脚本，按阶段开放，接受同行检验。

02 DATA

验证数据公开

Benchmark datasets and reproduction scripts — run, compare, and verify.

对标数据集与复现脚本一并公开，任何人都能运行、对比、验证。

03 ROADMAP

路线图公开

Every version transparently documents: what was solved, what was learned, and what comes next.

每个版本透明记录：解决了什么问题，遇到了哪些困难，下一步方向。

04 COMMUNITY

社区流程公开

Proposals, reviews, merges, governance — all documented, open to all.

提案、评审、合并、治理 — 流程写在 README 里，均可参与。
